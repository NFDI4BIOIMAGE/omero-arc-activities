# Contributing to omero-arc-activities

Welcome! Thank you for your interest in contributing to the **omero-arc-activities** repository. This project serves as a central hub for collecting, linking, and describing interoperability activities between OMERO and ARC (Annotated Research Context).

## How to Contribute

We welcome contributions in several forms:

- **Adding Activities**: Share reports from hackathons, workshops, or meetings.
- **Tutorials & Guides**: Contribute documentation or step-by-step guides for OMERO-ARC workflows.
- **External Links**: Open an issue or PR to link to relevant publications, presentations, or related repositories.
- **Feedback & Questions**: Use [GitHub Issues](https://github.com/NFDI4BIOIMAGE/omero-arc-activities/issues) to suggest improvements or ask questions about the project structure.

## Contribution Workflow

To maintain the quality and structure of this repository, please follow these steps:

1. **Fork or Branch**: If you have permissions, create a new branch from `main`. Otherwise, fork the repository.
2. **Follow Directory Structure**: Place your contribution in the appropriate directory as defined in the [README.md](README.md):
   - `hackathons/`: Project reports or documentation from events.
   - `tutorials/`: Educational material and "getting started" guides.
   - `publications/` or `posters-and-presentations/`: Links and metadata for research outputs.
3. **Include a README**: If you are adding a new sub-directory (e.g., a specific hackathon project), please include a `README.md` within that folder explaining its content.
4. **Submit a Pull Request (PR)**:
   - Open a PR against the `main` branch.
   - Provide a clear description of what you are adding or changing.
   - **Review Rule**: As per our branch protection rules, at least **one approving review** from a maintainer is required before merging.

## Code of Conduct

We expect all contributors to maintain a respectful and inclusive environment. Please be professional in your interactions within issues and pull requests.
