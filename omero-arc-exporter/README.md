# Implementation

The prototype for omero-arc exporter is available here:

https://github.com/cmohl2013/omero-arc

This repo aims to export data and metadata from OMERO (Open Microscopy Environment Remote Objects) in an ARC (Annotated Research Context)-like folder structure.

Futher, due to changes in the dependent tools over the period and with the focus on ISA (Investigation Study Assay) metadata a new repo can be found here :

https://github.com/cmohl2013/omero-isa
